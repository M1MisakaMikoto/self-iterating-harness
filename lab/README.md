# Agent Lab（框架）

本目录是 Agent Lab 的**框架**（预制模板，完整记录）：规范、词汇表、决策记录与维护约定。

实际由 agent 工作产生的实验、报告、证据等**具体内容**不放在本仓库，留在使用该框架的项目本地（项目 `.dev` 中区分"服务内容不记录 / 产出内容记录"）。

## 目录

```text
.dev/lab/
├─ AGENTS.md            # lab 内 agent 约定（薄规则）
├─ CONTEXT.md           # 词汇表（只放术语定义）
├─ README.md            # 本文件
└─ docs/
   ├─ norms.md          # 文档写作规范
   └─ adr/              # 架构决策记录
```

使用方式：把本目录内容复制到项目的 `.dev/lab/`（或按项目实际结构放置），再按需补充具体实验内容。
