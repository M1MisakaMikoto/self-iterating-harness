# MAC 消融实验

更换模型时，对 **MAC（模型辅助内容）** 逐条做消融实验，验证每条规则在新模型下是否仍能增强工作能力。**UAC 不做消融**（跨模型稳定）。

## 使用方式

1. 复制本文件为 `ABLATION-<模型名>.md`，或按项目记录习惯命名。
2. 对每条 MAC 规则，用同一任务做两次对照：开 / 关该规则。
3. 记录模型、任务、结果与结论。
4. 结论为"保留 / 调整 / 移除"；调整或移除须写明原因与证据。

## 待验证的 MAC 清单

1. MAC-1：落地改动方案后评估工作结果是否与方案一致。
2. MAC-2：排查问题用测试和 log，不用一味读代码；排查 git 变动用 `--shortstat` 和实际 diff 行验证。
3. MAC-3：探索性任务或用户有纠正行为要求时启用路径记忆；任务结束按 Stop hook 确认写入记录，写入后回读分析优化工作流程。
4. MAC-4：代码修改与工作行为纠正分开记录；行为纠正只记录为工作规范，不混入代码变更或 Git 提交。
