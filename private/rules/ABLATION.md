# MAC 消融实验

更换模型时，对 **MAC（模型辅助内容）** 逐条做消融实验，验证每条规则在新模型下是否仍能增强工作能力。**UAC 不做消融**（跨模型稳定）。

## 使用方式

1. 复制本文件为 `ABLATION-<模型名>.md`，或按项目记录习惯命名。
2. 对每条 MAC 规则，用同一任务做两次对照：开 / 关该规则。
3. 记录模型、任务、结果与结论。
4. 结论为"保留 / 调整 / 移除"；调整或移除须写明原因与证据。

## 待验证的 MAC 清单

1. MAC-1：落地改动方案后评估工作结果是否与方案一致。
2. MAC-2：最小验证（修改 → 测试 → 撤回 → 报告）。
3. MAC-3：排查问题用测试和 log，不用一味读代码。
4. MAC-4：及时记录用户纠正要求，任务后回读分析工作流程。
5. MAC-5：禁止随便写兜底逻辑，默认写断言。
6. MAC-6：排查 git 变动用 `--shortstat` 和实际 diff 行验证。
7. MAC-7：用户明确变更范围时先完成该变更再汇报。
8. MAC-8：代码修改与行为纠正两类事项分开记录。
